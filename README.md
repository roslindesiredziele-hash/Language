Overview
A modular C++ framework for modeling natural and programming languages through structured abstractions. It explores object‑oriented design and linguistic concepts using English, French, and custom language models, supported by clear architecture and tests.

Features
NaturalLanguage, English, French, and ProgrammingLanguage classes

Object‑oriented design with clear abstractions

Modular architecture

Unit tests demonstrating usage

Extensible structure for adding new languages

Project Structure
src/ — core language classes

tests/ — unit tests

external/ — dependencies

Language.vcxproj — Visual Studio project

Build & Run
Open the .vcxproj in Visual Studio and build the solution.

Tests
Run the test executable in tests/ or through Visual Studio’s test runner.
